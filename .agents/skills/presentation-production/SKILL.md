# 演讲演示制作

本 Skill 负责当前完整演示流程。演示方法尚在探索，不预先拆成更多 Skills，也不套用 B-roll 的字幕时间线和视觉规则。

所有 pnpm 命令从工作区根目录执行。命令参数中的 `projects/` 路径相对于 `app/`。

## 流程

1. 继续已有项目时先读取 `MEMORY.md`。将完整讲稿保存在项目的 `script.md`，不得用摘要替代。
2. 尚无 `project.json` 时运行 `pnpm scaffold <project-id>`；空 `source.srt` 只是当前脚手架产物，不是演示输入。
3. 完整阅读讲稿，在 `presentation-plan.md` 中按讲稿段落记录页面标题和范围，请用户审查。
4. 读取 `docs/PRESENTATION_VISUAL_STYLE.md`，为每页补充一段可直接想象的 `画面设计：`，请用户再次审查。
5. 两次审查完成后，按目标横版 1920 × 1080 或竖版 1080 × 1920 生成 Scene JSON、图层和必要动画。
6. 在编辑器中检查每页开场和动画结束状态。
7. 用户明确要求时导出 HTML，再打开新生成的 `index.html` 检查点击、键盘翻页和当前页重播。

两次审查都必须完成，除非用户明确要求跳过。一个项目只保存一个画布版本；横版和竖版使用不同项目 ID，不能互相覆盖。同时制作两个版本时先确认两个项目 ID，再分别完成规划、设计、生成、检查和交付。

`presentation-plan.md` 使用简洁结构：

```md
## Page 01：页面主题

讲稿范围：从“……”到“……”。

画面设计：用一段具体文字说明画面元素的位置、出现顺序和最终状态。
```

## 设计要求

- 一页只承载一个清晰的信息任务，但不按每句话机械拆页。
- 画面描述使用具体空间和变化语言，说明元素在哪里、如何出现、最终停在哪里。
- 每页必须能独立打开和重播，不能依赖观众看过上一页的动画状态。
- Scene 时长只控制页内动画和最终停留状态，换页由用户手动触发，不需要 SRT 时间轴。
- 为满足共享 Project 时间线，第一页 `startFrame` 为 0，后续页面从上一页结束帧开始；HTML 打开每页时仍从该页局部第 0 帧播放。
- 横版和竖版分别设计，不直接缩放或照搬固定坐标。
- 当前没有成熟演示视觉规则时，优先形成可审查的具体方案，不把一次结果提升为长期模板。

## 交付

```bash
pnpm export:html <project-id>
```

`export:html` 会校验 Project / Scene 数据、顺序和图片素材，不使用 B-roll 的 SRT 时间校验。导出前还要人工确认没有空素材和制作提示，并实际检查离线 `index.html` 的翻页、键盘操作和当前页重播。当前 HTML 演示不包含项目音频。

完成重要审查或交付后，按 [project-memory](../project-memory/SKILL.md) 提出候选记忆，不直接写入。
