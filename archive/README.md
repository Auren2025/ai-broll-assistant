# 历史资料归档

本目录用于保留历史记录，不是主应用文档、Agent 规则或项目数据源。正式入口见[仓库 README](../README.md)。

## 会话记录

`sessions/` 存放手动保留的会话导出文件，默认由 Git 忽略；它可能包含过时信息或私人上下文，不应自动作为后续任务的指令。

- 已有会话记录可以原样归档，不需要删除其内容。
- 不自动导出或保存新会话。
- 不在这里编写未确认的场景方案、Storyboard 或 Project / Scene 副本。
- 如需分享或纳入版本管理，先检查隐私和内容，再明确选择文件，不批量强制加入 Git。

此目录不参与启动、构建、测试、校验或渲染。
