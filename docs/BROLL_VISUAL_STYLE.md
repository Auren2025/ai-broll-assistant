# B-roll 视觉设计参考

本文记录从实际作品和反馈中形成的当前视觉方法，供 Designer 构思画面、Builder 落地细节时参考。它不是固定模板，可以随实践继续调整。

具体场景方案写入项目的 `scene-plan.md`，制作步骤见 [B-roll 制作 Skill](../.agents/skills/broll-production/SKILL.md)。根本事实以 [AGENTS.md](../AGENTS.md) 为准，新偏好按 [project-memory Skill](../.agents/skills/project-memory/SKILL.md) 提请确认。

## 视觉方向

- 画面应在不依赖真人镜头的情况下清楚承载口播，可结合动画、产品录屏和有意留白。
- 追求简洁、规整、易读的 Keynote 式产品讲解，用少量足够大的元素建立明确重心。
- 优先保证信息准确和表达合适，再处理尺寸、阅读顺序、动画和视觉修饰。
- 主画面直接表达对象、结构或关系，不靠额外标题、卡片和底部总结制造完成感。
- 允许同一构图稳定承载较长解释，不为每句话增加元素或动画。

## 选择表达方式

| 内容 | 优先考虑 | 避免 |
| --- | --- | --- |
| 产品识别、作品回顾 | 真实 Logo、封面或产品主视觉 | 伪 Logo、重复名称和额外口号 |
| 分类、目录、名称、命令、路径 | 大文字、列表、网格或有意义的分组 | 为每项强配图标，把并列关系画成因果流程 |
| 界面、配置和操作证据 | 真实截图及必要局部，配少量标注 | 重画伪界面，让观众阅读缩小的整屏内容 |
| 原理、流程、包含、对比和状态变化 | 必要对象与关系组成的示意结构 | 只写结论，不表现需要解释的关系 |
| 连续产品操作 | 实际录屏，B-roll 只做必要辅助 | 用连续截图模拟完整操作 |

文字和形状可以表达抽象关系，但不能伪装成真实产品界面。选择最直接的表达，不为丰富画面强行添加图片或图标。

## 构图与层级

- 先确定观众第一眼看什么，以及之后的阅读方向。焦点可以是 Logo、截图、文字列表、对比或关系结构。
- 元素保持足够大，在常用缩小预览中仍能读清关键文字和截图区域；留白用于突出内容，不用于掩盖内容过小。
- 同类对象使用一致尺寸、间距和对齐，默认不旋转、不随机散落或交错堆叠。
- 优先使用大对象直接排布，通过尺度、位置和留白形成结构，不默认给每个对象套卡片。
- 容器只用于表达真实分组、包含、对比或界面区域；通常一层语义容器已经足够。
- 标题、箭头、底板和底部结论按理解需要使用，删除后不影响表达的元素不应保留。
- 普通内容场景不自动显示 Scene `topic`。`scene-plan.md` 中明确标记的过场标题使用中央大标题，不套用到普通场景。

## 文字与色彩

- 面向中文观众时以中文为主，产品名、命令、代码和惯用术语保留英文。
- 画面文字使用名称、关键词、分类、清单或必要结论，不照抄整段字幕，也不增加口播没有表达的能力和口号。
- 优先用位置、字号、间距和分组建立层级；粗体和颜色只用于真正的重点。
- 以横版 `my-design` 为比例参考时，分组说明约 40px、主要列表约 50px；这只是起点，竖版和实际内容需要重新判断。
- 透明背景与黑色辅助底板上以白色和灰色文字为主，品牌色来自真实素材，其余颜色少量且稳定地用于分组、身份或状态。

## 图片与素材

- Logo、图标、真实界面和具体插画使用真实图片，不用字母、形状或手绘图标冒充。
- 图片必须承担识别、展示或证据作用；纯名称、命令、路径和抽象分类不必逐项配图。
- 设计时说明使用整图还是局部、必须看清的区域、宽高比和透明底要求。
- 已有素材先查看实际内容再布局，不能只根据文件名推测。
- 字标已经包含清楚名称时不重复标注；截图自带的信息足够时不重复写一遍。

## 动画节奏

- 静态是起点。只有新对象出现、关系或状态变化、流程推进和必要焦点转移才需要动画。
- 先描述开场画面、随口播发生的变化和最终停留，再选择具体动画。
- 以阅读单元而不是图层数量安排出现顺序；一组内容可以整体出现，需要逐项讲解时再分步。
- 动画方向保持连贯、幅度克制，并给观众留下读完和看清最终状态的时间。
- 不追求动画种类和数量；简单入场可以贯穿整个项目，移动、缩放或退场只在帮助理解时使用。

## 横版与竖版

- 横版使用 1920 × 1080，竖版使用 1080 × 1920；两者共享视觉原则，但必须分别设计构图。
- 当前参考作品均为横版，只能借鉴方法，不能把坐标、字号和横向排布直接复制到竖版。
- 横版适合左右关系和横向流程；竖版优先考虑上中下层级、纵向推进和更短的文字行。
- 两个版本都应在各自实际预览尺寸中检查重心、可读性和留白。
